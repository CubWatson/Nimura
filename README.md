# Nimura

A public Minecraft modpack built from a collection of mods I enjoy.

**[Download on Modrinth](https://modrinth.com/project/nimura)**

## About this repository

This repo exists only as an **issue tracker** for the pack. The pack itself, its changelog, and the full mod list live on Modrinth.

## Reporting a problem

1. Search [existing issues](https://github.com/CubWatson/Nimura/issues?q=is%3Aissue) to see if it's already been reported.
2. Open a [new issue](https://github.com/CubWatson/Nimura/issues/new/choose) and pick **Bug report**.
3. Upload your `logs/latest.log` or crash report to [mclo.gs](https://mclo.gs) and include the link.

Got an idea for a mod? Use the **Mod suggestion** template. Nimura only uses mods hosted on Modrinth.
